# Generation Style Selection

## Purpose

Let the user choose the visual style applied to generated images.

## User Story

As a user, I want to select an image style so that the generated results match my preferred look.

## Acceptance Criteria

- The available styles are Animation, Illustration, and Sketch.
- Animation is selected initially.
- The selected style is used for the next generation.
- Restarting retains the selected style.
